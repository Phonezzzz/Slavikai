# Domain modeling

Use the repository's existing canonical vocabulary and challenge contradictions between prose and
current code. Sharpen overloaded terms with concrete scenarios. Keep glossary facts separate from
implementation decisions and specifications. Treat CONTEXT.md and ADRs as explicit artifacts:
never create or edit them merely because a term or trade-off was discussed; first obtain specific
authorization for that write.
