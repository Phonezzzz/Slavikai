# Docs map

Навигационная карта документации после PR-0..PR-7.

- `architecture/` — runtime canon, текущая архитектура и legacy boundaries.
- `agent/` — обязательные правила и runtime policies для агентов.
- `for-humans/` — пользовательские и эксплуатационные инструкции.
- `workflow/` — процесс разработки, проверки и contribution workflow.
- `archive/` — исторические документы и старые roadmap/materials.
