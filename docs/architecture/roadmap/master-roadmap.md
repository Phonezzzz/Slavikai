# Master architecture roadmap

- **Назначение:** после Discovery связывать архитектурные цели с последовательностью
  реализации.
- **Содержит:** только согласованные work streams, зависимости, milestones и критерии
  завершения.
- **Не содержит:** roadmap до завершения Capability Discovery, неподтверждённые задачи или
  детальный task tracking.
- **Обновлять:** после принятых изменений target architecture, priorities или dependencies.
