# Memory — gaps

- **Назначение:** сопоставлять подтверждённые Current State и Target для capability domain
  `memory`.
- **Содержит:** доказанные расхождения, их влияние, зависимости и статус верификации.
- **Не содержит:** неподтверждённые проблемы, готовые implementation tasks или решения,
  не прошедшие архитектурное рассмотрение.
- **Обновлять:** после изменения `current.md`, `target.md` или подтверждения нового gap.
