# Memory — target

- **Назначение:** описывать согласованный target-state capability domain `memory`.
- **Содержит:** требования, границы, инварианты и acceptance criteria, подтверждённые после
  Capability Discovery.
- **Не содержит:** current implementation, исследовательские заметки, gaps или
  неподтверждённый дизайн.
- **Обновлять:** после принятых target-решений или изменения подтверждённых требований.
