# Non-goals

- **Назначение:** явно ограничивать область целевой архитектуры SlavikAI.
- **Содержит:** согласованные цели, которые система намеренно не преследует, с контекстом
  границы.
- **Не содержит:** временно отложенные задачи, неподтверждённые предположения или дефекты
  current implementation.
- **Обновлять:** при изменении product scope или принятии решения, меняющего границы системы.
