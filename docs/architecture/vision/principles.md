# Principles

- **Для чего:** задавать принципы и правила trade-off, по которым оцениваются архитектурные решения.
- **Сюда:** принципы с обоснованием, приоритет при конфликте, примеры допустимого/недопустимого применения.
- **Не сюда:** разовые решения, детали реализации, список фич.
- **Обновлять:** при принятии нового принципа или пересмотре существующего.
