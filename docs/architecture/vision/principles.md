# Architecture principles

- **Назначение:** хранить критерии, которыми руководствуются при архитектурных решениях.
- **Содержит:** принятые, проверяемые принципы и краткое обоснование каждого из них.
- **Не содержит:** дизайн конкретных компонентов, список capabilities или решения без
  согласованного статуса.
- **Обновлять:** когда принцип принят, уточнён или отменён отдельным архитектурным решением.
