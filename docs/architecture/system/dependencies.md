# System dependencies

- **Назначение:** фиксировать архитектурно значимые зависимости внутри и вне SlavikAI.
- **Содержит:** подтверждённые зависимости, направления связи, владельцев контрактов и
  существенные ограничения.
- **Не содержит:** полный package inventory, догадки о связях или задачи по замене
  dependencies.
- **Обновлять:** при подтверждённом изменении системной зависимости или её контракта.
