# System boundaries

- **Назначение:** фиксировать ответственность SlavikAI и границы между системными областями.
- **Содержит:** подтверждённые ownership, trust, process, deployment и integration boundaries.
- **Не содержит:** абстрактные слои без evidence, внутренности отдельных capabilities или
  implementation tasks.
- **Обновлять:** когда принято решение, меняющее ответственность или системную границу.
