# Capability map

- **Назначение:** показывать подтверждённый набор capabilities и их системные связи.
- **Содержит:** результаты Capability Discovery, границы domains и проверенные отношения
  между ними.
- **Не содержит:** предположительно полный список до завершения Discovery, component design
  или implementation roadmap.
- **Обновлять:** после подтверждённого изменения capability inventory или его границ.
