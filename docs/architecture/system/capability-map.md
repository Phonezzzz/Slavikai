# Capability Map

- **Для чего:** описывать карту capabilities и их взаимосвязи.
- **Сюда:** подтверждённый/решённый инвентарь capabilities, ownership, границы, граф зависимостей.
- **Не сюда:** детальные внутренности каждой capability, шаги реализации.
- **Обновлять:** при изменении инвентаря capabilities — после Capability Discovery и решений.
