# Data flows

- **Назначение:** описывать проверенные потоки данных через границы системы.
- **Содержит:** источники, получателей, преобразования, storage points и trust boundaries для
  согласованных сценариев.
- **Не содержит:** неподтверждённые runtime paths, component implementation details или
  sequence diagrams ради заполнения.
- **Обновлять:** при изменении подтверждённого flow, его данных или системных границ.
