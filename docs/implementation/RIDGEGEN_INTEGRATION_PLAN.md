# RidgeGen integration — план после production consolidation

Дата: 2026-09-25; база `origin/main=bcaff71`. Источник: [исследование](../research/RIDGEGEN_ARCHITECTURE_RESEARCH.md) и [аудит](../audits/RIDGEGEN_INTEGRATION_AUDIT.md). Термины RidgeGen — архитектурный reference, не копируемая спецификация. `docs/runtime_contract_claims.json` и canonical contracts определяют current/Target. Каждый future increment требует отдельного scope и решения владельца; этот PR реализует только №0.

| **0. Policy batch-stop — этот PR** | Только `core/tool_loop.py`: sync/stream loop прекращает оставшиеся tool calls и итерации после `ToolGateway` policy deny или запрета model-hidden tool. | Canonical Auto v1, ToolGateway и approvals сохраняются. Schema migration нет. `tests/test_tool_loop.py`: настоящий gateway deny, следующий tool не вызван, stream выдаёт error terminal. `bcaff71` failed-tool `FAILED_WORKER` tests остаются без изменений. |

Tests обязаны отменять уже блокирующий вызов и проверять durable/observable terminal и effects. Никакой реализации в этом PR. |

Старые RidgeGen commits остаются историческим исследованием; их полный cherry-pick запрещён семантическим конфликтом с fail-closed Auto в `bcaff71`.
