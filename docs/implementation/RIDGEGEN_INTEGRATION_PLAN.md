# RidgeGen integration — план после production consolidation

Дата: 2026-09-25; база `origin/main=bcaff71`. Источник: [исследование](../research/RIDGEGEN_ARCHITECTURE_RESEARCH.md) и [аудит](../audits/RIDGEGEN_INTEGRATION_AUDIT.md). Термины RidgeGen — архитектурный reference, не копируемая спецификация. `docs/runtime_contract_claims.json` и canonical contracts определяют current/Target. Каждый future increment требует отдельного scope и решения владельца; этот PR реализует только №0.

Schema migration нет. `tests/test_agent_modes_logic.py`, `tests/test_auto_runtime.py`, `tests/test_tool_loop.py`: token identity, cancellation до/во время batch, отсутствие verifier, отказ до следующего tool.
